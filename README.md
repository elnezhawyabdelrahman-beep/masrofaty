# مصروفاتي

تطبيق ويب عربي لإدارة الدخل والمصروفات والميزانيات، بتصميم متجاوب يدعم التثبيت كتطبيق PWA.

## المميزات
- لوحة ملخص للرصيد والدخل والمصروفات الشهرية.
- تسجيل دخل ومصروف مع تصنيفات وتاريخ وملاحظات.
- سجل عمليات مع بحث وفلترة حسب النوع والشهر.
- ميزانيات شهرية لكل تصنيف مع مؤشرات الاقتراب من الحد.
- رسوم مبسطة للتصنيفات وتقارير آخر 6 شهور.
- تصدير العمليات CSV ونسخ احتياطي JSON واستعادة نسخة.
- وضع ليلي واختيار العملة.
- تخزين محلي على الجهاز، مع دعم العمل دون اتصال بعد أول تحميل.
- شعار وأيقونات أصلية للتطبيق وزر تثبيت يظهر عندما يدعم المتصفح ذلك.

## التشغيل
ارفع محتويات المستودع إلى GitHub Pages أو أي استضافة ملفات ثابتة. من Settings → Pages اختر النشر من فرع `main` ومجلد `/ (root)`.

## ملاحظات مهمة
- البيانات محفوظة محليًا على نفس الجهاز والمتصفح، وليست متزامنة بين الأجهزة.
- التنبيهات تتطلب موافقة المستخدم. إشعارات الدفع المجدولة والتذكير أثناء إغلاق التطبيق تحتاج خدمة خلفية (Push server)، لذلك لا يدّعي هذا الإصدار توفير تنبيهات مجدولة في الخلفية.
- يفضّل تشغيل الموقع عبر HTTPS حتى تعمل خصائص PWA وService Worker.

## التقنية
HTML, CSS, JavaScript بدون مكتبات خارجية أو مفاتيح API.
