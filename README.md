# مصروفاتي

تطبيق ويب عربي لإدارة الدخل والمصروفات والميزانيات، بتصميم متجاوب وPWA.

## المميزات
- لوحة ملخص للرصيد والدخل والمصروفات.
- تصنيف تلقائي للمصروفات مع إمكانية اختيار التصنيف يدويًا وتعديله عند تسجيل العملية أو تحريرها.
- سجل عمليات يدعم تعديل العملية وحذفها والبحث والفلترة.
- البحث عن صور المنتجات في Open Food Facts؛ لا يعرض صورة منتج عشوائي إذا لم يجد تطابقًا.
- سجل عمليات مع البحث والفلترة.
- ميزانيات حسب التصنيف مع إشعار عند 80% وعند تجاوز الحد، بعد منح إذن الإشعارات.
- تقارير شهرية ورسوم مبسطة.
- تصدير CSV ونسخ احتياطي JSON واستعادة.
- أوضاع فاتح وداكن واتباع مظهر الجهاز، مع حفظ الاختيار.
- المساعد المحلي يحتفظ بآخر 80 رسالة على الجهاز.
- عملات متعددة، تثبيت PWA والعمل دون اتصال بعد أول تحميل.

## النشر
من Settings → Pages اختر Deploy from a branch ثم main و/(root).

## حدود مهمة
- صور المنتجات تعتمد على توفر المنتج في قاعدة Open Food Facts والإنترنت؛ بعض المنتجات المحلية قد لا تكون مدرجة.
- إشعارات الميزانية تظهر عند تسجيل مصروف جديد بينما التطبيق يعمل. الإشعارات المجدولة أثناء إغلاق التطبيق تحتاج خدمة Push خلفية غير مضافة في هذا الإصدار.
- البيانات محفوظة محليًا في المتصفح ولا تتزامن بين الأجهزة.
- خصائص PWA والإشعارات تحتاج HTTPS.

## التقنية
HTML وCSS وJavaScript وService Worker، بدون خادم أو مفاتيح API.
